## Cómo reportar una vulnerabilidad

**No abras un Issue público.** Usa el canal privado de GitHub:

1. Pestaña **Security → Report a vulnerability** (*Private vulnerability reporting*).
2. Describe el problema, cómo reproducirlo y el impacto.

Respuesta inicial en un máximo de 7 días. Este es un proyecto educativo con datos ficticios; aun así, cualquier exposición de secretos o datos personales se trata como incidente (ver [docs/seguridad.md](docs/seguridad.md)).
