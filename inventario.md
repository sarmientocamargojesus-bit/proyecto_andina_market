# Inventario del repositorio

Propósito de cada carpeta y archivo principal (capítulo 01).

| Ruta | Propósito |
|---|---|
| `README.md` | Presentación del proyecto y cómo ejecutarlo |
| `proyecto.md` | Definición del caso: problema, usuarios y criterios de éxito |
| `inventario.md` | Este inventario |
| `bitacora.md` | Línea base de datos y registro de trabajo con Git |
| `tabla_cambios.md` | Registro de cambios por capítulo |
| `data/` | `ventas.csv` (12 ventas ficticias) y `diccionario.md` |
| `src/` | `resumen.py`: lee el CSV y calcula el resumen |
| `tests/` | Pruebas con `unittest` |
| `docs/` | Manual, guías, evidencias y sitio web |
| `.github/` | Plantillas de Issues y PR, CODEOWNERS y workflows |
| `.gitignore` | Archivos que Git no debe versionar |
| `LICENSE` | Licencia MIT |
