# Guía: cuenta y perfil de GitHub (capítulo 02 · lo haces tú)

> Esta guía no contiene datos personales. Las capturas o fichas con tu información van solo en el informe, no en el repositorio.

## Perfil

1. Foto de perfil → **Settings → Public profile**.
2. *Name*: el que quieras mostrar (puede ser solo tu nombre de pila).
3. *Bio*: una línea profesional, p. ej. "Estudiante de análisis de datos · Git y GitHub".
4. *Public email*: **Don't show my email address**.
5. *Pronouns*, *URL*, *Location*: opcionales.

## Correo privado (recomendado)

*Settings → Emails*:

- ☑ **Keep my email addresses private** → los commits hechos desde la web usan una dirección `@users.noreply.github.com`.
- ☑ **Block command line pushes that expose my email**.

## Seguridad

- **2FA**: ver [2fa-ssh.md](2fa-ssh.md).
- *Settings → Sessions*: cierra las sesiones que no reconozcas.

## Notificaciones

*Settings → Notifications*:

| Opción | Recomendación |
|---|---|
| *Watching* | Solo los repositorios en los que trabajas |
| *Participating, @mentions and custom* | Web + correo |
| *Actions* | **Only notify for failed workflows** |
| *Dependabot alerts* | Correo semanal |
